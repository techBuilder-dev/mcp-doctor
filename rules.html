MCP Doctor — Rule Reference

Every check MCP Doctor runs on a claude_desktop_config.json or .cursor/mcp.json, what each means, and how to fix it.

← Back to the validator

error — breaks the server warning — likely to bite you info — heads-up

Missing mcpServers key missing-top-level

Every config must have a top-level mcpServers object. It is the root key all server definitions live under.

Fix: wrap your servers under { "mcpServers": { ... } }.

mcpServers is an array servers-not-object

Servers are named keys inside an object, not array entries. Using [ ... ] instead of { ... } is a common mistake.

Fix: use an object keyed by server name.

Server is not a valid object server-not-object

Each server value must be an object with at least a command or url.

Fix: make the value an object, e.g. { "command": "npx", "args": [...] }.

No command or url no-command-or-url

An active server needs either a command (stdio) or a url (HTTP). Without one, the client cannot connect.

Fix: add a command for a local process or a url for a remote server.

args is not an array args-not-array

args must be an array of strings, even for a single argument. A bare string causes a startup failure.

Fix: wrap args in [ ].

env is not an object env-not-object

env must be a flat key-value object mapping variable names to values.

Fix: use "env": { "KEY": "value" }.

Duplicate server name duplicate-server

Two servers share a name. The later one silently overwrites the first — JSON parsers keep only the last duplicate key, so the first server vanishes with no error.

Fix: give each server a unique name (e.g. filesystem-home, filesystem-work).

Deprecated SSE transport deprecated-sse

The SSE transport was deprecated in MCP spec 2025-03-26. Claude Desktop and Cursor moved to Streamable HTTP. SSE servers often fail silently with a bare "Connection closed".

Fix: move the server to Streamable HTTP and use "transport": "http" with a /mcp endpoint.

Filesystem server missing directory path filesystem-no-path

The filesystem server requires at least one allowed directory argument. Without it the server starts but rejects all file operations with an opaque error.

Fix: add a path after the package, e.g. "/Users/you/documents".

Windows path with unescaped backslashes windows-path-separators

JSON requires doubled backslashes. "C:\Users\me" is parsed as escape sequences (\t = tab, \n = newline), corrupting the path — or failing to parse entirely.

Fix: double every backslash (C:\\Users\\me) or use forward slashes.

URL ends in /sse sse-url-pattern

A /sse endpoint usually means a legacy SSE server. Modern Streamable HTTP servers use /mcp. This commonly causes "Connection closed".

Fix: point at the server's Streamable HTTP endpoint instead.

Empty environment variable empty-env-var

An env key exists but its value is "". The server starts, then any operation needing that key fails with a cryptic auth or "undefined" error.

Fix: set the real value (MCP Doctor's "Auto-fix" can drop in a placeholder).

npx without -y npx-missing-y-flag

Without -y, npx prompts "Need to install the following packages?" interactively. The client subprocess has no TTY to answer, so the server hangs silently.

Fix: add -y as the first npx argument.

Remote server over plain HTTP http-url-not-localhost

A non-localhost http:// URL sends your tool calls and responses in the clear, exposing them to network eavesdropping.

Fix: use https:// for any remote server.

Path uses ~ path-with-tilde

Tilde expansion is a shell feature. Clients launch MCP servers directly (no shell), so ~/ may not expand to your home directory.

Fix: use the absolute path.

Possible package typo package-typo

The package name is not a known MCP server but is one or two characters away from one (e.g. server-brave-serch → server-brave-search). A typo means the package never installs and the server silently fails.

Fix: correct the package name to the suggested match.

Tool count ceiling tool-count-ceiling

Cursor has a soft ceiling of ~40 active tools across all servers. With 8+ active servers (avg ~5 tools each) you can exceed it; tools beyond the limit are silently dropped and the agent never knows.

Fix: park servers you rarely use with "disabled": true.

Missing a known required key missing-required-env

A recognized server (e.g. server-github) is missing the env var it normally needs to authenticate (e.g. GITHUB_PERSONAL_ACCESS_TOKEN).

Fix: add the expected key to the server's env block.

Server is disabled disabled-server

The server has "disabled": true and will not load. Purely informational.

Fix: remove the flag or set it to false to re-enable.

uvx command uvx-command

uvx needs the uv Python package manager on your PATH. On Windows it sometimes needs the full path to uvx.exe.

Fix: install uv; verify with uvx --version.

node without a full path node-path-check

Claude Desktop on macOS/Linux doesn't always inherit your shell PATH. If node came from nvm/fnm, a bare node can be "command not found".

Fix: use the absolute path (find it with which node).

docker command docker-command

Docker-based servers need Docker Desktop running, or they fail with spawn docker ENOENT.

Fix: start Docker Desktop before your client.

Python -m module python-module-path

A bare python3 -m ... may pick up the wrong interpreter if the server needs a specific virtualenv.

Fix: point command at the venv's Python binary.

References a schema version schema-version-check

The config carries a version or $schema field. These differ between Claude Desktop and Cursor.

Fix: confirm it matches your client.
